How triggers & tools differ▸
Trigger = what starts an agent (an event: a timer, a queue message, or a connector event like “a new email arrived”). MCP tool = what an agent can do (an action: “send an email”, “query docs”).
💡 Same connector, two roles: Office 365 can start the app (trigger: “new email”) and be a tool it uses (action: “draft reply”).
